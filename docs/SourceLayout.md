# 소스 구조

`src/core/`는 공통 API와 값·매개변수, `hardware/`는 장치와 메모리, `models/`는 모델 카탈로그와 메타데이터, `runtimes/`는 런타임 인터페이스·구현, `service/`는 서비스·전송, `media/`는 멀티모달 입력을 소유한다. 구현과 관련 헤더를 함께 둔다.

빌드용 연결 헤더와 설치된 실제 헤더는 기존 평탄한 공개 include 이름과 CMake 타깃을 유지한다. 매개변수 카탈로그의 로컬 출처 경로도 `src/core/Types.h`로 갱신하며 헤더 내용·해시·선언 행은 변경하지 않는다. `iiLocalLLM.source_layout`은 소스 분류를 검사하고 실제 모델 추론은 별도의 명시적 검증 범위로 남긴다.
