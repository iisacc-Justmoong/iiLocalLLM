# 전체 가중치 무결성 확인의 네이티브 해시

ModelCatalog는 설치와 로딩에서 모델 파일의 모든 바이트를 SHA-256으로 확인한다. 이 계약은 유지하면서 macOS의 스트리밍 계산을 시스템 CommonCrypto 구현으로 옮겼다. 다른 플랫폼의 기존 구현과 읽기·복사·취소 경계는 유지한다.

변경은 파일 일부만 검사하거나 검증을 생략하는 캐시가 아니다. 기존 1 MiB 읽기마다 취소를 검사하고 같은 바이트 전체를 계산하며 결과와 파일 크기를 매니페스트와 비교한다. 큰 가중치의 시작 지연을 줄이되 기존 메모리 예산이나 요청 기한을 늘리지 않는다.

model_digest 회귀 검사는 빈 입력·abc·백만 개의 a로 구성한 표준 벡터를 검사한다. 바이트별·31바이트·64 KiB 분할, 반복 결과 조회와 조회 이후 계속 갱신도 검사한다. 기존 카탈로그 및 실제 모델 검사는 설치·변조·전체 파일 검증을 별도로 확인한다.


macOS의 순차 검증에는 커널 `F_RDADVISE`로 최대 8 MiB 읽기 범위를 예고한다. 4 MiB 진행마다 다음 범위를 요청하여 저장 장치가 읽기를 병합할 수 있게 한다. 실제 읽기는 기존 1 MiB 단위이고 전체 바이트의 해시와 취소 검사는 동일하다. 힌트 미지원·실패 시 원래 읽기로 계속하며 파일 위치·소유권을 바꾸지 않는다. `model_digest`는 힌트 적용 전후의 위치 불변과 전체 파일 해시 동일성, 범위 밖·닫힌 파일의 무해한 처리도 검사한다.
